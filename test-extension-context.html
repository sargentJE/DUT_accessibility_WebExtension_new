Chrome Extension Context Test

This page tests the Accessibility Helper extension's serialization in a real browser context.

Test Instructions:

  1. Load the Chrome extension
  2. Open the extension popup on this page
  3. Navigate to Page 2 and fill out some checkbox groups
  4. Use the browser's developer tools to check console logs
  5. Verify that checkbox groups are serialized as arrays

Expected Behavior:

  • Checkbox Groups: Should serialize as arrays (e.g., input_method: ["keyboard_mouse", "touch"])
  • Single Checkboxes: Should serialize as strings
  • Radio Buttons: Should serialize as strings
  • Text Fields: Should serialize as strings
  • Multi-Select: Should serialize as arrays (if any exist)
